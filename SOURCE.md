# Public source snapshots

The original No Type source code is available under Apache License 2.0,
copyright 2026 Darlingfxx02. See LICENSE and NOTICE. Third-party components and
model weights retain their own licenses.

The application lives in `CrossPlatform/`. This public repository contains
reviewed source snapshots, build instructions and official stable downloads.
Collaborative development, experiments and Dev history stay in a separate
private repository. Public changes can be proposed through issues and pull
requests; retain authorship and notices when contributing.

The initial source snapshot is dated 2026-10-13 and is based on the 0.1.11
application line. It includes the subsequent customization improvements,
sidebar visibility fix and Apache licensing change. It is identified by the
`source-2026-10-13` tag and `SOURCE-SNAPSHOT.json`.

Previously published v0.1.11 installers predate this source snapshot and retain
their original packaged notices. Publishing source does not replace those
installers. Future stable binary releases should identify the exact public
source commit used to build them.
